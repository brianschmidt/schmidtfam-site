Here a number of fun and helpful Russian links assembled by the students in Middlebury's Basic Russian Language Course this year. Click and Enjoy!

 

  • Russia Today: An English language resource with news, weather and other links.
  • Pepsi in Russia(n ): Just for the fun of it.
  • Moscow weather: Try it in Russian.
  • Russia's weather. All you want to know and more.
  • Yaroslavl State University. You can study Russian there through Middlebury College.
  • Russian Bazaar. A set of ads in Russian for the United States. Use the WIN font encoding.
  • Mueller's English-Russian Dictionary. Type in the English and out comes the Russian.
  • Kenga.ru? So what? I dislike pages with just more links, but this one can give you railway and plane schedules in Russian, and a great collection of postcards in Russian. Try it, you'll like it.
  • St. Petersburg. The Russian one.
  • The Bible in Russian. It needs work with fonts, but the instructions are clear and user friendly.
  • Nezavisimaya gazeta. The Independent-a well respected Russian language newspaer
  • Rusnet. A useful set of materials for anyone interested in learning Russian.
  • Russian search engines. Start here for entry in a Russian's world.
